# Solar Power Generation Prediction

Predicts the power generated by a solar plant from weather and sun-position data, using a Random Forest model.

**Live app:** https://solar-power-forecastingg.streamlit.app/

## Features
- Scenario presets and input checks
- Result in Joules and kWh
- Charts for sun position, cloud cover and feature importance
- CSV upload for many predictions at once

## Tech
Python, Pandas, Scikit-learn, Streamlit

## Run locally
pip install -r requirements.txt
streamlit run App.py
